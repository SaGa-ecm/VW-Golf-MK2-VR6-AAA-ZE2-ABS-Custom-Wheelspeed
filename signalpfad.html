Signalpfad · VSS / GALA

UNBESTÄTIGT: Mk04/Mk20-Geberkompatibilität ANNAHME: k = 960 (per GPS verifizieren)
/
Arduino-Pfad: G47 Braun → SG Pin 5 · G47 Braun-Weiß → SG Pin 23 · LM393 → D2 (INT0) → D9 → PC817 → BC547 → Tacho T28/27. Der Wandler ersetzt das GALA-Signal; ab T28/27 identische Kette.

Station wählen

Station in der Kette anklicken (Geber → G1/11 → U1/11 → T28/27 → Tacho → T28/07 → U2/02 → ECU 65 / Tempomat / Radio).

FAKTOR-Rechner

FAKTOR = (960 × 4) / (Zähne × 1000 / Reifenumfang). Hz@100 km/h = v / Umfang × Zähne × FAKTOR.

–

Referenz: 195/50R15 (1,83 m), 45 Zähne, k=960 → FAKTOR ≈ 0,156 · Hz@100 ≈ 107 Hz. Abweichende Reifen/Zähne → neu berechnen oder per GPS kalibrieren.
